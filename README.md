# Agent Registry 🤖

Unified detection, configuration, plugin, and chat history discovery registry for AI coding agent CLIs.

## Features

- **Multi-Agent CLI Detection**: Detects Claude Code, Antigravity (`agy`), OpenCode, Roo Code, Cline, Aider, Copilot, Grok, Cursor, Windsurf, Codex, Goose, etc.
- **Config & Plugin Paths**: Standardized inspection of local config files, plugin directories, and custom skills paths.
- **Chat Log Discovery**: Multi-agent chat history log scanning (`discover_agent_chats`).
